🚀 CÓMO USAR
═══════════════════════════════════════════════════════════════════════════════

OPCIÓN 1: CASA OS (Docker)
──────────────────────────
1. cd /DATA/AppData
2. git clone <repo-url> ramona-music
3. cd ramona-music
4. cp .env.example .env
5. Edita .env con tu MUSIC_PATH y LASTFM_API_KEY
6. docker-compose up -d
7. Abre http://localhost:3000

OPCIÓN 2: ANDROID (APK)
──────────────────────
1. cd mobile
2. npm install
3. eas login (crea cuenta en https://expo.dev)
4. eas build --platform android
5. Descarga el APK
6. Instala en tu dispositivo Android
7. En Ajustes, configura URL del servidor

🔧 CONFIGURACIÓN RÁPIDA
═══════════════════════════════════════════════════════════════════════════════

1. OBTENER API KEY LAST.FM (GRATUITA):
   https://www.last.fm/api/account/create
   → Copiar API Key
   → Agregar a .env

2. CREAR CUENTA EXPO (GRATUITA):
   https://expo.dev/signup
   → Para compilar APK Android

3. CONFIGURAR .env:
   MUSIC_PATH=/DATA/Media/Music (tu ruta real)
   LASTFM_API_KEY=tu_key_aqui
   REACT_APP_API_URL=http://localhost:3001
